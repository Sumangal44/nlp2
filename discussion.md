# 11. Remove stopwords

```python
filtered_tokens = [token for token in tokens if token.lower() not in stop_words]
```

This is the **main line of the program**.

It is called a **list comprehension**.

Let's break it down.

### `for token in tokens`

This takes each token one by one.

For example:

```text
Natural
Language
Processing
is
a
branch
of
Artificial
Intelligence
```

---

### `token.lower()`

This converts the token to lowercase.

For example:

```python
"Natural".lower()
```

gives:

```text
natural
```

And:

```python
"Processing".lower()
```

gives:

```text
processing
```

This helps make the stopword comparison case-insensitive.

---

### `not in stop_words`

This checks whether the lowercase token is **not** a stopword.

For example:

```python
"is".lower() not in stop_words
```

Since `"is"` is a stopword:

```text
False
```

So `"is"` is removed.

But:

```python
"Natural".lower() not in stop_words
```

is:

```text
True
```

So `"Natural"` remains.

---

Therefore:

```python
filtered_tokens
```
```python

```

# 3. stemming

### 2. Import Porter Stemmer

```python
from nltk.stem import PorterStemmer
```

This imports the `PorterStemmer` class from NLTK.

**Stemming** means reducing related words to a common stem.

Examples:

```text
playing  → play
played   → play
studying → studi
```

Important: stemming does **not always produce a proper English word**. For example, Porter Stemmer commonly produces `studi` from `studying`.

---

### 3. Import word tokenizer

```python
from nltk.tokenize import word_tokenize
```

This imports `word_tokenize()`.

It divides the sentence into individual tokens.

For example:

```text
The students are studying.
```

becomes:

```python
['The', 'students', 'are', 'studying', '.']
```

---

### 4. Download tokenizer data

```python
nltk.download("punkt_tab")
```

`word_tokenize()` needs NLTK's tokenizer data.

This command downloads the required `punkt_tab` resource if it isn't already installed.

---

### 5. Input text

```python
text = "The students are studying and playing games."
```

Here, `text` is a variable containing our input sentence.


---

### 6. Tokenization

```python

```

The sentence is divided into individual tokens.

The result is approximately:

```python
['The', 'students', 'are', 'studying', 'and', 'playing', 'games', '.']
```


---

### 7. Create the stemmer

```python
stemmer = PorterStemmer()
```

Here we create an object of the `PorterStemmer` class.

The variable:

```python
stemmer
```

will now be used to perform stemming.

---

### 8. Perform stemming

```python
stemmed_words = [stemmer.stem(word) for word in words]
```

This is a **list comprehension**.

Let's break it down:

```python
for word in words
```

means:

> Take each word from the `words` list one by one.

Then:

```python
stemmer.stem(word)
```

applies the Porter stemming algorithm to that word.

For example:

```text
students  → student
studying  → studi
playing   → play
games     → game
```

The complete result is typically:

```python
['the', 'student', 'are', 'studi', 'and', 'play', 'game', '.']
```

Notice that:

```text
studying → studi
```

This is **not a mistake**. It demonstrates an important property of stemming: the result is a stem, not necessarily a valid dictionary word.

# Understanding the POS tags

| Word     | POS Tag | Meaning                           |
| -------- | ------- | --------------------------------- |
| The      | DT      | Determiner                        |
| student  | NN      | Noun                              |
| is       | VBZ     | Verb, 3rd-person singular present |
| studying | VBG     | Verb, gerund/present participle   |
| in       | IN      | Preposition                       |
| the      | DT      | Determiner                        |
| library  | NN      | Noun                              |
| .        | .       | Punctuation                       |

### Important tags

**NN** → Noun

```text
student
library
book
```

**VBZ** → Verb, 3rd-person singular present

```text
is
runs
plays
```

**VBG** → Verb, gerund/present participle

```text
studying
playing
running
```

**DT** → Determiner

```text
the
a
an
```

**IN** → Preposition

```text
in
on
at
with
```

# 6. word2vector


### 2. Import Word2Vec

```python
from gensim.models import Word2Vec
```

Here we import the `Word2Vec` model from the `gensim` library.

**Gensim** is a Python library commonly used for NLP tasks involving:

* Word embeddings
* Topic modeling
* Semantic similarity
* Text representation

`Word2Vec` learns a numerical representation for words from surrounding words in sentences.

---

# 3. Create training sentences

```python
sentences = [
    ["The", "cat", "is", "sitting", "on", "the", "mat"],
    ["The", "dog", "is", "playing", "with", "the", "ball"],
    ["The", "bird", "is", "flying", "in", "the", "sky"],
    ["The", "fish", "is", "swimming", "in", "the", "water"],
    ["The", "child", "is", "playing", "in", "the", "park"],
]
```

This creates the **training dataset**.

Notice that every sentence is already divided into words.

For example:

```python
["The", "cat", "is", "sitting", "on", "the", "mat"]
```

is one sentence.

There are **5 sentences** in total.

### Why do we need sentences?

Word2Vec learns from the **context** in which words occur.

For example:

```text
The cat is sitting on the mat
The dog is playing with the ball
```

The model observes which words occur near one another.

---

# 4. Create the Word2Vec model

```python
model = Word2Vec(sentences, vector_size=50, window=2, min_count=1, workers=4)
```

This is the most important line.

It creates and trains the Word2Vec model.

Let's understand each parameter.

---

## `sentences`

```python
Word2Vec(sentences, ...)
```

This tells Word2Vec which data it should learn from.

Our training data is:

```text
cat, dog, bird, fish, child, ...
```

---

## `vector_size=50`

```python
vector_size=50
```

This means each word will be represented by a vector containing **50 numerical values**.

For example, conceptually:

```text
cat →
[0.12, -0.43, 0.25, ..., 0.08]
```

There are 50 numbers.

So:

```text
Word
 ↓
50-dimensional numerical vector
```

This numerical vector is called a **word embedding**.

---

## `window=2`

```python
window=2
```

This specifies the size of the context window.

The model considers words within approximately **2 positions** around the target word.

For example:

```text
The cat is sitting on the mat
```

For `cat`, nearby words include:

```text
The
is
```

depending on the position and training context.

The idea is that words appearing in similar contexts can develop similar representations.

---

## `min_count=1`

```python
min_count=1
```

This tells Word2Vec to include words that appear at least **once** in the training data.

If we used:

```python
min_count=2
```

then words appearing only once would generally be excluded from the vocabulary.

Because our dataset is very small, `min_count=1` allows all words to remain available.

---

## `workers=4`

```python
workers=4
```

This tells Gensim to use **4 worker threads** when training.

It can make training faster on larger datasets.

For this tiny example, the difference will be negligible.

---

# 6. Get the embedding of `cat`

```python
print("\nword embedding cat\n", model.wv["cat"])
```

This is very important.

### `model.wv`

`wv` gives access to the model's learned **word vectors**.

### `["cat"]`

This asks:

> Give me the vector representing the word `"cat"`.

Because we specified:

```python
vector_size=50
```

the result contains **50 numerical values**.

For example, you may see something like:

```text
word embedding cat
[ 0.012 -0.034  0.021 ... ]
```

The exact numbers will vary because Word2Vec training involves random initialization and this is a very small training dataset.

### Important

The numbers themselves don't directly mean:

```text
0.5 = animal
0.3 = size
```

Instead, the vector is a learned mathematical representation whose relationships to other vectors can capture aspects of word usage.

---

# 7. Find words similar to `cat`

```python
print("\nword similar to cat\n", model.wv.most_similar("cat", topn=3))
```

This asks the model:

> Which 3 words have vectors most similar to the vector of `"cat"`?

### `most_similar("cat")`

The model compares the embedding of `cat` with other word embeddings.

### `topn=3`

It asks for the top **3** similar words.

The output has the general form:

```text
word similar to cat
[('dog', 0.xxxx), ('bird', 0.xxxx), ('fish', 0.xxxx)]
```

The exact words and similarity scores can vary considerably with such a tiny dataset.

The number beside each word is a **similarity score**, commonly based on cosine similarity.
